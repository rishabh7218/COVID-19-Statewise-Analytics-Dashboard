COVID-19 Statewise Analytics

Data-driven analysis of COVID-19 cases across Indian states using Microsoft Excel and Power BI. Explore statewise confirmed cases, recoveries and fatalities.

Explore Dashboard View GitHub

Project Overview

This project analyzes COVID-19 statewise data in India. It uses Excel for data analysis and Power BI for interactive data visualization, helping users understand the distribution of confirmed cases, recoveries and deaths across states.
